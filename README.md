# 🎓 Student Score Predictor | Machine Learning Project

A Machine Learning web application that predicts students' final scores based on study hours, attendance, previous exam scores, and sleep hours.

## 📌 About the Project

The **Student Score Predictor** is a beginner-friendly Machine Learning project developed using Python and Flask. It uses a Linear Regression model to estimate a student's final score based on the input provided by the user.

The project demonstrates how a Machine Learning model can be integrated into a web application to make predictions through a simple and user-friendly interface.

## ✨ Key Features

- Predicts students' final scores using Machine Learning.
- Accepts study hours per day as input.
- Considers attendance percentage.
- Uses previous exam scores for prediction.
- Includes sleep hours per night as an input feature.
- Displays predicted marks through a web interface.
- Simple and easy-to-use design.

## ⚙️ Getting Started

Follow these steps to run the project on your local machine.

### Prerequisites

- Python installed on your system
- pip package installer

### Installation

**1. Download the repository**

Click the green **Code** button on GitHub and select **Download ZIP**. Extract the downloaded ZIP file.

**2. Open the project folder**

Open the extracted project folder in VS Code or a terminal.

**3. Install the required libraries**

```bash
python -m pip install -r requirements.txt
```

**4. Run the application**

```bash
python app.py
```

**5. Open the application**

Open your browser and visit:

```text
http://127.0.0.1:5000
```

## 🚀 How to Use

1. Enter your daily study hours.
2. Enter your attendance percentage.
3. Enter your previous exam score.
4. Enter your sleep hours per night.
5. Click **Predict Final Marks**.
6. View the predicted final score on the screen.
